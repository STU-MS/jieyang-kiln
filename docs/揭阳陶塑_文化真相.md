## 1. 定义

**揭阳陶塑制作技艺**是流传于广东省揭阳市的传统雕塑工艺，以本地赤红地格土为胎、色釉为饰，题材取儒、释、道、士、农、工、商、学、渔及戏剧神话传说，经选泥配泥、泥塑小稿、翻模印制、修坯、素烧、施釉、煅烧等工序，产出人物摆件与建筑陶塑。其艺术语言是人物大胆夸张、形神兼备，脸、手、脚露胎不施釉，衣褶施窑变色釉，形成粗犷与细腻、素胎与色釉的强烈对比；风格圆润喜庆、精巧简洁、装饰性强，在潮汕陶塑大系统中自成体系，同时融汇佛山石湾陶塑的传神粗犷与潮汕戏曲、木雕、泥塑的装饰性。2013 年列入第五批省级非物质文化遗产名录，省级代表性传承人陈茂辉（2017 年获评）。[1][2][3][4]

### 1.1 四个不能省的关键词

| 关键词 | 含义 | 来源 |
|---|---|---|
| **自成体系** | 在潮汕陶塑大系统中「自成体系、独具一格」 | [3][4] |
| **融汇石湾** | 不只是「借鉴」：陈保国 1953 年拜石湾刘传为师，2015 年作为「石湾公仔现当代最知名 19 位大师」之一参展陈家祠；陈茂辉「较为完整地继承了陈保国陶塑和刘传陶塑的创作经验和艺术理论」 | [2][5] |
| **脸手脚素胎、衣褶窑变釉** | 核心视觉语言，直接继承石湾「以不施釉的陶泥胎骨表现肌肤」 | [1][5][7] |
| **中高温施釉烧成为主** | 现行做法；早期是「低温烧坯后加彩二次烧」，后借鉴石湾改中高温 | [4][5][6] |

### 1.2 不是什么

- **不做日用器**。揭阳陶塑的载体是人物摆件与建筑陶塑（屋脊、照壁），不是杯、碗、瓶。[1][3][4]
- **不是枫溪瓷**。枫溪瓷烧制技艺是潮州市的国家级非遗，做通花瓷、瓷花、人物瓷塑，1300℃ 以上高温瓷。揭阳陶塑是省级非遗，做陶塑，中高温。两者同属潮汕，但是两个项目。[11]
- **不是大吴泥塑**。大吴泥塑是潮州浮洋的国家级非遗，贴塑为主，不施釉彩。本文不涉及。

## 2. 工艺流程

### 2.1 官方九道（省文化馆申报材料 [1]，2024 揭阳日报同 [3]）

| # | 工序 | 做什么 | 细节与依据 |
|---|---|---|---|
| ① | **选泥、配泥、练泥** | 选本地赤红地格土，搭配不同产地陶土，练匀 | 地格土 [4]；「不同产地成型与煅烧性能不同需搭配」见 §6，一手来源未找到 |
| ② | **泥塑小稿** | 作者构思，做出原稿，定下整件作品的基调 | 手法：雕、琢、刻、划 + 捏、粘、贴、捺 [4]；「造型、姿态是人物塑像的艺术典型化的体现，形、神是作品的灵魂」[5] |
| ③ | **成型塑造** | 在小稿基础上塑造完整泥坯 | 可按需调整比例：《老子出关》「不按常规比例构图，人物形象比例调高，青牛比例压小」[5] |
| ④ | **翻石膏模** | 以泥稿翻制石膏模具 | 三条产品线由此分岔：原作单件 / 开模精修 / 开模批量 [4] |
| ⑤ | **作品印制** | 陶土入模印制成型 | 陈茂辉「行彩桥」金狮爷即此路 [4] |
| ⑥ | **作者修坯、作品润色** | 出模后手工修整 | 限量精品由作者亲修 [4] |
| ⑦ | **晒干、低温素烧** | 阴干后低温素烧 | 与「一次烧成为主」并存，素烧可能是可选保险而非必经，见 §6 |
| ⑧ | **配釉、施釉** | 脸、手、脚露胎不施釉；衣褶施窑变色釉 | 「陶泥烧成后色泽熏褐，适宜塑造人物肌肤」[5]；「灰色釉煅烧之后会变成红色，施釉时要考虑釉彩厚薄、釉色窑变」[4] |
| ⑨ | **成型煅烧** | 中高温烧成，产生窑变 | 旧潮汕做法「白釉低温烧制，后着附颜色」，后借鉴石湾改中高温 [5][6]；具体温度见 §6 |

### 2.2 陈茂辉口述的八环节（2026 [4]）

选泥 → 泥塑小稿 → 翻石膏模 → 印制成型 → 修坯 → 晾干 → 施釉 → 烧制。

与九道的差异：配泥练泥并入选泥，未单提素烧。两版不矛盾，九道是申报材料的规范表述。

### 2.3 对照：石湾陶塑六环节（国家非遗 Ⅷ-3 [7][8]）

构思创作 → 泥料炼制 → 成形 → 装饰 → 上釉 → 龙窑煅烧。技法分**刀塑、按塑、捏塑、贴塑**四种 [7][8]。揭阳的「雕琢刻划 + 捏粘贴捺」是这套技法的延伸。

### 2.4 烧成方式的演变

| 时期 | 做法 | 来源 |
|---|---|---|
| 早期潮汕陶塑 | 白釉低温烧制，烧后着色，色彩单调 | [5][6] |
| 现行（陈保国起） | 借鉴石湾，中高温施釉烧成，窑变色彩古朴厚重；「一次烧制为主」 | [4][5][6] |

> 旧文档写「先晒干低温素烧，后中温施釉烧制」作为**工艺顺序**，是对 [1]「先以低温陶坯加彩，后为中温施釉烧制为主」的误读。原文说的是**历史演变**（先 / 后 = 早期 / 后来），不是工序先后。

## 3. 艺术特征

| 特征 | 具体表现 | 来源 |
|---|---|---|
| 题材 | 儒、释、道、士、农、工、商、学、渔；戏剧神话传说；历史名人；潮汕民俗 | [1][3][4] |
| 造型 | 人物大胆夸张，高度写实与适度夸张结合，不循常规 | [1][4][5] |
| 风格 | 圆润喜庆、精巧、简洁、诙谐、装饰性强；古朴厚重、雅俗共赏 | [1][3][4] |
| 肌肤处理 | 脸、手、脚及裸露肌体**露胎不施釉**，利用陶泥烧成后熏褐色泽 | [1][5] |
| 衣饰处理 | 衣褶、衣裤施窑变色釉（绿、白、水绿、石墨等） | [1][5] |
| 釉色预判 | 生釉色 ≠ 成品色，「灰色釉煅烧之后会变成红色」 | [4] |
| 应用场景 | 早期宫庙祠堂建筑装饰（屋脊、照壁）；当代转向摆件、收藏品、文创 | [1][4] |

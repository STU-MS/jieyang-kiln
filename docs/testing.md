# 测试标准

## 两问检验（每个测试写完必问）

1. **故意改坏业务行为，它会红吗？**——不会红的测试是装饰品，删。
2. **重构实现但行为不变，它要改吗？**——要跟着改的测试是在测实现不是测行为，是负资产，删。

## 怎么写

- **模拟内核（src/sim/）是纯函数，直接测**：同种子 + 同操作序列必须得到同结果。窑变唯一性用抽样验证「不同输入 → 不同输出」，不断言具体像素。
- **替身只出现在外部边界**：localStorage / IndexedDB 用内存替身，seeded RNG / 时间可注入。Three.js 渲染不进单测，走真浏览器走查（见「取证」）。
- **音频总线**：测「缺文件静音、不抛错」，不测真实发声。
- **前端交互**：断言用户可见行为（点击后状态切换、弹层出现、跳过生效），不断言 DOM 结构、类名、恒定文案存在。
- **边界行为必须测**：每个 bug 修复配一正一负。游戏域必测边界：
  - 泥体积守恒（拉坯改形前后体积不变，塌坯判定）；
  - seeded RNG 可复现（同种子同操作 → 同窑变）；
  - 存档兼容：旧 `schemaVersion` 存档 + 新代码必须能加载或安全降级（等价于 Unself 的跨版本迁移闸门）；
  - 后台标签页时钟冻结（visibilitychange 回切不追赶、不跳变）；
  - 空态（首局无存档）、失败态（资产缺失退回占位不崩溃）。

## 禁项

- 断言「代码在不在」：文件存在、内部调用计数、源码子串。
- 断言「页面有这段文字」：模板子串、快照测试。边界：状态切换后的可见结果（成功/失败提示）允许断言；恒定静态文案禁止。
- 恒真 / 自证循环：测试断言自己的 fixture。
- 测试不得依赖目录与包名：断言里不写仓库相对路径、目录层级；定位仓库内资源按结构解析（例：向上找 `package.json`）。

## 门禁（= CI 同一套，PR 前必须全绿）

```sh
pnpm install --frozen-lockfile   # ① 锁文件必须一致
pnpm typecheck                   # ② 类型检查
pnpm build                       # ③ tsc + vite 产物构建（防「测试绿但打不了包」）
pnpm test                        # ④ Vitest（含资产/文案清单校验，原 check:assets 并入此处）
```

- 顺序固定；本地残留 `dist/` 出现的绿色是假绿，验收一律以 CI（干净树）为准。
- 结构类错误（tsconfig extends 断链、workspace glob 对不上）由 ③ 的 tsc/vite 兜住，不设独立结构闸门。

## 开工前边界自查（写第一行代码前逐条自问自答，答案进 issue 或 PR；前 5 项总要过一遍，后 3 项写「不涉及」也要显式写出）

1. **并发**：同一操作并发打进来（连点确认、双标签同局、重放进存档）会怎样？存档写入是幂等的吗？
2. **写入异常**：localStorage / IndexedDB 写失败（隐私模式、配额满）时降级路径是什么？会中断游玩吗？
3. **空态**：首局无存档、清单无正式资产、知识卡收集为零时，用户看到的是合理界面还是报错/白屏？
4. **失败态**：资产缺失、WebGL 不可用、Worker 报错时，退回占位/降级页还是崩溃？
5. **唯一性**：窑变结果唯一性的前提（seeded RNG + 操作序列盐）成立吗？单存档槽覆盖会丢什么？
6. 不涉及：大小写归一（无账号体系）。
7. 不涉及：明文落库（无密码/token/密钥）。
8. 不涉及：权限保真（无服务端 API）。

## 五关验收（合并前缺一不可）

1. diff/边界复核：PR 只碰 issue 范围内文件，越界改动要么退回要么明示批准。
2. 新测试测行为（不是实现细节）；**UI / 交互类改动必须附真浏览器渲染取证**（截图落 PR，注明日期 + commit 基线）。
3. **红灯验证**：把改动改坏，测试必红，输出贴 PR。没有红灯证据的测试不算交付。
4. 四段门禁全绿（= CI 同一套）。
5. 提交带 sign-off，PR 含 `closes #N` 与验收对照表。

## 取证留档规则

- 涉及真实浏览器、真机的核验：截图/录屏 + 命令或操作原文 + 时间，作为评论或 PR 描述落档；文字转述不算证据。
- 评论开头注明**日期 + commit 基线**，如 `2026-10-17 · 基线 cbc5ebd`。
- 验收记录只存对应 issue / PR，不落 docs/。

## 职责边界

- 视觉与动线走查（拉坯手感、帧率、触屏一致性）执行真浏览器走查，单测不替代肉眼。
- 纯重构 PR：旧测试零改动通过——这是「测行为不测实现」的直接推论。

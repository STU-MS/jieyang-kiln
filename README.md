# 揭阳陶塑数字体验游戏 · Jieyang Kiln

**用五道工序，做一只世上仅此一只的陶杯。**
A 3–8 minute browser game: mix the clay, throw the cup, dry and bisque it, glaze it, then open the kiln — every cup comes out one of a kind.

揭阳陶塑是广东揭阳的本土陶艺传统：赤红地格土、中温素烧加釉烧、素胎与窑变色釉相映。本项目把它做成一局 3–8 分钟、开箱即玩的纯 Web 工艺流程模拟器——不做写实陶艺仿真，而是让你在「水土配比—湿度环境—火候窑变」三股力量的夹缝里，亲手做出属于自己的一只杯。

## 玩法流程

```
调配陶土 → 拉坯塑型 → 晒干与素烧 → 配釉施釉 → 成型煅烧（开窑窑变）
```

- **调配陶土**：三种本地泥料 + 水量滑块，配出「可塑而不塌、干而不裂」的泥；
- **拉坯塑型**：不规定器形、不计时。整体 / 内外 / 抹平三种手法，泥的体积守恒，转速太高会把口沿甩开；
- **晒干与素烧**：看天做陶。选晾位、翻面、遮盖，再跟住素烧温升曲线的目标带；
- **配釉施釉**：六种本地釉方任选两种叠加，青灰、酱褐、米黄为基底；
- **成型煅烧**：可控的火候曲线 + 不可控的窑变。开窑那一刻，种子、泥料、釉方、温度、气氛与杯体几何共同生成一张独一无二的窑变贴图。

### 特色

- 🌦️ **环境是真随机**：季节与天气按揭阳实况气候建模（回南天、龙舟水、冷空气……），同一只杯十月做和四月做完全是两回事；
- 🔥 **窑变不可复刻**：全链路 seeded RNG + 操作序列加盐，理论上没有两只相同的杯；
- 🏺 **失败落在「外形」上**：塌坯、惊釉、流釉挂足……所有惩罚可见、可归因、可收藏进「残器谱」，没有抽象扣分；
- 🤝 **包容设计**：默认无声，听障、色弱、无 WebGL 均可走完主流程；桌面鼠标与移动触屏同一套交互。

## 技术栈

- **构建**：Vite + TypeScript
- **渲染**：Three.js（车削曲面杯体、程序化窑变贴图，三维场景在 `requestAnimationFrame` 中更新，不随 React 每帧重绘）
- **界面**：React 18
- **测试**：Vitest
- **包管理**：pnpm

模拟内核是纯函数——没有画面也能跑完一局状态；美术与音频均为占位资源，正式资产按 id 替换，不经过编辑器资源库。

## 本地开发

```bash
pnpm install
pnpm dev            # 启动开发服务器
pnpm test           # 运行 Vitest 测试
pnpm build          # 类型检查 + 产物构建
pnpm check:assets   # 校验资产清单
```

要求：Node.js ≥ 18，pnpm ≥ 8。浏览器要求 Chrome / Edge ≥ 110、Safari ≥ 16、Firefox ≥ 110（WebGL 2）。

## 目录结构

```
docs/       设计文档与开发计划（中文，一手依据）
src/
  sim/      纯函数模拟内核（泥料、形变、窑变）
  game/     环节流程与状态机
  render/   Three.js 场景与材质
  stages/   各玩法环节实现
  ui/       React 界面组件
  data/     数值表（占位值，灰度后回写）
  content/  文案、知识卡与旁白
  persist/  localStorage / IndexedDB 存档
  audio/    按 id 取音频的空总线（缺文件即静音）
```

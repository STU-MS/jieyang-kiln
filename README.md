# 揭阳陶塑 · Jieyang Taosu

**把一团泥拆开、捏成一个人、上釉、进窑——开窑时看你猜没猜对。**

一局 6–7 分钟的浏览器 3D 游戏。揭阳陶塑制作技艺是广东省级非物质文化遗产（2013 年入名录），这个游戏让你走一遍它的核心工序：拆泥、捏塑、定姿势、穿衣、上釉、烧制。

## 玩法

```
拆泥 → 捏 → 姿势 → 衣服 → 阴干 → 上釉 → 烧制
```

- **拆泥定夸张**：一团泥分给头、身、臂、腿，分多少就是多大。泥是守恒的，头分多了身子就小。
- **捏是滑杆**：点一个部位，泥球连续变成默认形状，然后用滑杆调。臂和腿加长必须调细，泥就那么多。
- **先姿势后衣服**：骨骼摆好了衣服才穿得上。
- **上釉看不到成品**：刷上去的是生釉色，烧出来是另一个色。灰釉烧成红。脸上涂不涂随你。

## 技术栈

- Vite + TypeScript + React 18
- Three.js（morph target 驱动滑杆，骨骼驱动姿势，canvas 贴图记录釉层）
- Vitest
- pnpm

人物基础网格来自 MakeHuman / MPFB2（CC0），离线用 Blender 烘成小 GLB。姿势是 VRMPose JSON。服装是 CC0 资产。没有自建美术。

## 本地开发

```bash
pnpm install
pnpm dev            # 开发服务器
pnpm test           # Vitest
pnpm typecheck      # 类型检查
pnpm build          # 产物构建
```

要求：Node.js ≥ 22，pnpm ≥ 11。浏览器 Chrome / Edge ≥ 110、Safari ≥ 16、Firefox ≥ 110（WebGL 2）。
